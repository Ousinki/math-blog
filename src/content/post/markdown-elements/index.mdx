### 懸浮註釋

在 MD 文件中使用 `[原文]{註釋}` 語法可以為[文字]\{註釋}添加註釋。但是在 MDX 文件，這個語法會被 JSX 解析器先處理，所以需要使用轉義符： `[原文]\{註釋}` 。

## Admonitions（提示框）

使用 `:::type` 語法創建提示框：

```md
:::note
這是一個 note 提示框
:::
```

### 支持的類型

:::note
**Note** - 用於一般信息
:::

:::tip
**Tip** - 用於提示和建議
:::

:::important
**Important** - 用於重要信息
:::

:::caution
**Caution** - 用於需要注意的事項
:::

:::warning
**Warning** - 用於警告信息
:::

### 自定義標題

```md
:::note[自定義標題]
內容...
:::
```

:::note[這是自定義標題]
這是帶有自定義標題的提示框
:::

## 可折疊的 Admonitions

使用 `{fold}` 或 `{fold=true}` 創建可折疊的提示框：

### 默認折疊

```md
:::warning{fold}
這是默認折疊的內容
:::
```

:::warning{fold}
這是默認折疊的內容，點擊標題展開
:::

### 默認展開（可折疊）

```md
:::note{fold=false}
這是默認展開但可折疊的內容
:::
```

:::note{fold=false}
這是默認展開但可折疊的內容
:::

### 語法總結

| 語法 | 效果 |
|------|------|
| `{fold}` | 默認折疊 |
| `{fold=true}` | 默認折疊 |
| `{fold=false}` | 默認展開（可折疊）|
| 無 `fold` | 不可折疊 |

## 視頻嵌入

### 本地視頻

將視頻放入 `public/video/` 目錄，使用 Video 組件：

```mdx
import Video from "../../../components/Video.astro";

<Video src="/video/my-video.mp4" />
```

### Bilibili 視頻

```html
<iframe
  src="//player.bilibili.com/player.html?bvid=BV1QVCwBeEYk&page=1"
  scrolling="no"
  border="0"
  frameborder="no"
  framespacing="0"
  allowfullscreen="true"
  width="100%"
  height="400"
  style="border-radius: 8px;"
></iframe>
```

### YouTube 視頻

```html
<iframe
  width="100%"
  height="400"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="YouTube video player"
  frameborder="0"
  allowfullscreen
  style="border-radius: 8px;"
></iframe>
```

### Video 組件參數

| 參數 | 類型 | 必填 | 說明 |
| --- | --- | --- | --- |
| `src` | string | ✅ | 視頻路徑（相對於 `public/`）|
| `type` | string | ❌ | 視頻 MIME 類型（默認 `video/mp4`）|
